# Known Issues

Read this file **before** creating an issue to check if it is already here.

## Online mode
- **Safari crashes with `java.lang.NullPointerException` when loading fonts:** We are well aware of the issue, which is caused by Safari implementing a different API which does not work with the current implementation, but this will be fixed once this repository gets a stable release. If this hapens, using Chrome is a better idea.

- **Minimap does not work:** I know this is an issue, we are currently investigating the issue of it. However, this is low on our priority list.

- **Save/Load from file is bugged and does not work properly:** This is highest in our priority list, but do be patient!

- **Some mods will make the game crash during initialisation:** Mods are not supported, as this build is still very experimental. Maybe in the future.
