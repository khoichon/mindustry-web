Mindustry, compiled into one offline file you can keep.

This build forks Arc, the engine Mindustry runs on, retargets its rendering, audio, and I/O to the web, then compiles the whole game from Java to JavaScript with TeaVM. What comes out is a single self-contained .html file — download it once and it runs forever, no server, JVM, or connection required.

RUNTIME: TeaVM

This build starts further upstream. Arc, the engine Mindustry itself is built on, is forked and modified so its rendering, audio, and I/O layers target the web instead of desktop backends. That modified engine — plus the game code — is then ahead-of-time compiled from Java to JavaScript with TeaVM. The result is bundled with all assets into a single self-contained .html file: open it in any browser, no server, JVM, or network required after download.
